## 核心觀點

產品感不是會提需求，而是能判斷：

- 什麼值得做。
- 該先做什麼。
- 做到什麼程度最剛好。
- 做完後是否真的改善使用者與業務結果。

AI 讓「把東西做出來」變快，但不會自動讓團隊做對的事。越容易快速交付，越需要有人能判斷價值、成本、風險與使用者情境。
